# 非遗展示收尾设计

用户已确认按分类、真实模型、体验修正、验证文档的顺序实施。

- 沿用 category：预设剪纸、木雕、苏绣、陶瓷、竹编、其他；编辑保留历史分类。公开分类只来自审核通过的作品，我的分类只来自本人作品。
- category 空值表示全部，服务端过滤保留审核或归属限制。分类最多 50 字，不覆盖历史分类。
- 真实模型需有可核实来源和授权；缺少资源时保留验收待办，不用模拟文件冒充非遗模型。
- 切回图片或隐藏页面暂停动画，返回恢复；图片失败有可见提示，选择另一张可恢复；进度正确显示中文。
- removeModel 只清除数据库关联，不删除文件；移除优先于 URL，与新上传文件冲突时拒绝提交。
- 迁移兼容 MySQL 8，可重复执行；未经确认不写现有业务数据库。
- 以服务、MVC、浏览器回归验证；保留现有工作区文件，不创建分支，不提交。
