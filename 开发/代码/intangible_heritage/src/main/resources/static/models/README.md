# 3D 模型资源

展品模型使用 glTF 2.0 格式。优先使用单文件 `.glb`，它通常包含模型、材质和纹理，发布与部署更简单。

## 放置模型

- 可将公开可访问的模型放在本目录，再在展品编辑页填写对应 URL，例如 `/models/ceramic-vase.glb`。
- 也可以在发布或编辑展品时直接上传 `.glb` 或 `.gltf` 文件；上传文件优先于填写的 URL。
- 上传文件保存在应用配置的上传目录 `uploads/heritage/models/`，数据库只保存访问 URL，不保存模型二进制内容。
- 不要将含有个人信息、未经授权或体积过大的模型提交到版本库。
- 如果展品没有配置模型地址，详情页会使用内置的交互式演示器皿模型，便于验收旋转、缩放和全屏功能；该模型不代表真实非遗展品。

## 使用 `.gltf`

`.gltf` 常引用同目录下的 `.bin` 几何数据和纹理图片。请保持文件名与相对目录结构不变，并确保这些依赖能够通过 Web 服务器访问。依赖资源必须允许浏览器跨源加载（CORS），若不便管理多个依赖文件，请改用 `.glb`。

## 注意事项

- 查看器按需从 jsDelivr 加载固定版本的 Three.js 模块，因此首次打开 3D 模式需要网络连接。
- 使用 HTTPS 页面时，模型 URL 也必须使用 HTTPS，避免浏览器混合内容拦截。
- 当前仓库没有提供经过确认的非遗展品模型；内置演示模型会明确标注为“交互式 3D 演示”，不会冒充真实展品。真实模型加载失败时，仍可切回图片展廊。

## 真实非遗模型待验收

截至 2026-10-07，尚未接入可核实授权和展品对应关系的真实非遗模型。已有上传目录内的 `model-bytes` 是测试占位内容，不能用于视觉验收。

接入前需提供：有效的单文件 GLB（当前单文件上传上限 10 MB）、展品名称和工艺类别、来源链接或创作者信息、许可证或授权说明、纹理和模型的使用权限。不得把通用模型或程序生成的器皿标记为真实展品。

接入后逐项记录：上传成功及保存路径、对应展品审核通过、模型加载成功、旋转/缩放/复位/全屏、图片与 3D 切换、404 与 CDN 不可用时的降级、移动端查看，以及模型与实物资料的一致性。

编辑时可用“移除当前模型关联”解除关联，不会删除资源文件。站内模型路径可直接填入模型地址输入框。
