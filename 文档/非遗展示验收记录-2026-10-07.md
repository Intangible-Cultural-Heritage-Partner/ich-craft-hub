## 验证方式

Java 项目目录：`开发/代码/intangible_heritage`。使用 Java 17。

```powershell
$env:HERITAGE_MYSQL_INTEGRATION='true'
.\mvnw.cmd '-Dmaven.compiler.useIncrementalCompilation=false' package -q
python -m unittest discover -s src/test/browser -v
```

浏览器测试依赖 Python Playwright 和 Chromium；本机已有，其他环境需自行安装 `playwright` 并执行 `python -m playwright install chromium`。

- 服务层测试覆盖分类保存/保留/查询、发布权限、编辑归属、上传、模型移除及冲突。
- MVC 单元测试覆盖分类参数绑定、个人筛选、历史分类回显。
- `HeritageExhibitIntegrationTest` 需显式设置 `HERITAGE_MYSQL_INTEGRATION=true`；使用本机 `localhost:3306`，从应用配置读取 MySQL 用户名和密码，账号须有创建和删除测试库权限。测试随机创建 `ich_exhibit_test_<UUID>` 数据库，写入仅测试数据并在结束时删除自己的测试库，不写业务库。
- 集成验证使用真实 MySQL、真实业务服务、MockMvc 和 Thymeleaf：发布→待审核不可公开→管理员审核→分类展示→详情→编辑移除模型→重新待审核；并检查非本人编辑被拒绝。
- 迁移测试在独立旧结构测试库插入记录，执行迁移两次，验证原记录保留且新增模型字段为空。
- Chromium 测试运行详情模板中的真实 JavaScript：图片失败和恢复、中文进度、切页签暂停/恢复、文档隐藏暂停。动画测试使用渲染计数桩，不验证实际 GPU 或真实模型渲染。
